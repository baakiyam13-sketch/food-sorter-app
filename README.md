# Food Sorter phone app

Phone web app for Ethan's food sorter school project (age 8): photograph a food item, an AI gives it a health score, the app shows 😀 healthy or 😞 junk, and tells the ESP8266 sorter board which bin to push it into.

Phase 1 (pretend board) is on the `phase-1-pretend-board` branch — see the open pull request.
